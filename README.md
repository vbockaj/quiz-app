# Speed Round

A timed multiple-choice quiz app built with HTML, CSS, and JavaScript - no frameworks, no dependencies. 

Answer 20 general-knowledge questions before a 15-second countdown runs out on each one, then review your score and see which questions you missed.

## Features

20 multiple-choice questions across geography, science, art, history, and computing
Per-question 15-second countdown, shown as both a numeric ring and a shrinking bar
Visual feedback on the correct and (if wrong) selected answer before moving to the next question
Auto-advances when time runs out, scored as incorrect
Results screen with total score, a verdict line, and a question-by-question review
Restart button to reshuffle through the same set again
Responsive layout, keyboard-focusable options, and reduced-motion support

## Built with

HTML5 - page structure (index.html)
CSS3 - styling, layout, and transitions, no framework (style.css)
JavaScript - quiz logic, timer, and DOM rendering (quiz.js)
